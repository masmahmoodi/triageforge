# TriageForge

TriageForge is an AI-powered GitHub issue triage platform.

## Workspace

- `apps/api`: Express and TypeScript backend
- `apps/web`: React, TypeScript, and Vite frontend
- `packages/contracts`: Shared Zod schemas and API contracts

## Required tools

- Node.js 24
- pnpm 11.20.0
- Git
- Docker Desktop

## Current status

The repository workspace has been initialized.

Application code has not been implemented yet.
